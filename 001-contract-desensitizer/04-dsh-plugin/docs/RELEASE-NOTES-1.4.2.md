# 1.4.2：识别与 PDF 复核修复（预发布）

## 更新内容

- PDF 文字层康熙部首归一化，改善特殊字符漏识别。
- 补充当事人列表人名、跨行公司名和引号内简称识别，减少公司后缀条款误报。
- DATE_、AMOUNT_、MONEY_ 前缀的自定义日期／金额规则随保留策略处理；规则助手拒绝裸词规则及不符合约定的日期规则。
- 同页同类型且位置重合的 OCR／文字层候选去重。
- 缩略图失败可重试，原页与导出预览分开加载，修复左右栏滚动同步。

## 卸载旧版、安装新版

1. DSH“插件”管理页找到“文书脱敏”，点击“卸载”，如有重启提示按提示操作。无需卸载 DSH，不要手动删除文书数据目录。
2. 下载本 Release 附件 `dsh-document-redactor-1.4.2.tgz`，无需解压。
3. “插件 → 添加插件”填写安装包完整路径。Windows 可 Shift＋右键“复制为路径”，粘贴后删除最外层双引号、保留路径内空格；Mac 在 Finder 选中文件，按 Option＋Command＋C 复制路径。
4. 按提示启用或重启，确认版本 1.4.2，打开脱敏工具。
5. 原来出现问题的文件须重新上传为新项目，旧项目识别结果不会自动刷新。

Windows 与 macOS 使用同一 TGZ。只填文件名会被当作在线包名，须使用完整路径。
