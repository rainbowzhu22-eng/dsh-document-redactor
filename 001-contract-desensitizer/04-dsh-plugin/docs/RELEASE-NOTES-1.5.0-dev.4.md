# 文书脱敏工作台 v1.5.0-dev.4 预发布

- 新增 XLSX 脱敏。支持复核工作簿中的单元格和批注，并保留受支持的公式。对工资表等报表，可用演示金额替换真实输入，让应发、实发和汇总等结果继续按保留的公式计算。导出时会检查原金额和旧公式缓存。
- PDF 的原页与导出预览可以同步缩放，支持输入百分比和适应宽度。
- Word、PDF、TXT、Markdown、Excel 导出，以及还原和下载，都会显示失败原因和处理建议。能定位时显示 Word 部件与控件或图片序号、PDF 页码或 Excel 单元格。

## 安装

下载 Release 附件中的 `dsh-document-redactor-1.5.0-dev.4.tgz`，保留压缩包。在 DSH 的「插件 → 添加插件」填入安装包完整路径，按提示启用或重启。升级前保留已有原件、映射文件和插件数据目录。

## 验证范围

Python 72 项与 Node 51 项回归通过。macOS 日常 DSH 的安装文件已核对，并用安装后的本机服务验证 Word 内容控件和工资表公式冲突的提示。日常 DSH 侧栏点击、Windows Excel 和用户原合同待现场验证。Excel 金额功能适用于受支持的公式，外发前应人工核对脱敏稿。
