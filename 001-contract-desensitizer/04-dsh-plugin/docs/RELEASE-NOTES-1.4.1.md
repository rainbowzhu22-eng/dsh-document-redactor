# 文书脱敏工作台 v1.4.1

本次新增初始化失败 FAQ，减少使用者手动找日志的步骤，沿用预发布渠道。

- FAQ 位于未打开／失败页面及“帮助与反馈”，失败时展开首项，无需启动 Python 服务即可查看。
- 一键复制只读排查指令，按“返回 DSH → 新建会话 → 粘贴发送”定位实际日志，保留版本、错误码和冲突包名；不自动安装或修改文件。
- 复制不可用时选中文字供手动复制；附下载源切换、完整安装地址和反馈材料说明。
- 环境安装、下载切源、OCR、规则与导出代码均未修改；本版未增加自动切源功能。
