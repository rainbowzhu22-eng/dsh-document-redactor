# 1.4.3-dev.4：Word控件与图片兼容修复（预发布）

本版集中修复两类DOCX导出拦截：内容控件结构未被识别，以及正常内嵌图片使用另一种VML引用方式时被误判。

## 更新内容

- 支持可完整扫描、未绑定的文本／富文本／日期／下拉框／文档部件控件，以及表格、嵌套控件中的文字脱敏与映射还原。
- 导出时清理日期缓存、列表选项和占位引用等控件元数据，避免原文重新回填；这些元数据不会由映射还原。
- 补全VML内嵌图片引用兼容，保留图片字节与关系；图片引用缺失、冲突和未知危险结构仍会拦截，不通过删除图片来绕过错误。
- 控件或图片确实无法处理时，提示所在部件、序号及原因，便于反馈。Word图片仅原样保留，图内文字仍需人工核对。

## 更新方法：卸载旧插件，再安装新版

1. 打开DSH左侧“插件”，找到“文书脱敏工作台”或`dsh-document-redactor`，卸载旧插件；如有重启提示按提示操作。保留原始文书、映射文件和用户数据目录，不要手动清理这些文件。
2. [下载新版TGZ安装包](https://github.com/rainbowzhu22-eng/dsh-document-redactor/releases/download/v1.4.3-dev.4/dsh-document-redactor-1.4.3-dev.4.tgz)，不要解压。
3. 复制TGZ完整路径：Mac在Finder选中文件后按Option＋Command＋C；Windows按Shift右键选择“复制为路径”。
4. 回到DSH“插件 → 添加插件”，粘贴完整路径；删除路径最外层的双引号，保留内部空格，点击安装，按提示启用或重启。
5. 重新上传原合同作为新项目，核对候选后再导出。旧会话不会自动使用新结果。
