# 1.4.3-dev.2 预发布说明

本版合并楼军有的图像脱敏反馈及后续正文误遮范围修复。与公开版 1.4.2 相比：

- 新增 PDF 印章、证件照片、手写签名、手印、证件区域候选和跨页案号片段处理。复用预览、人工补框、复核与导出，不自动覆写原文件。
- 图像候选逐项确认；图像检测失败或不完整时，必须处理提示并人工核对，才能继续导出。
- “投资方之关联方／投资方的关联方”等叙述前缀不再并入机构名；拆开显式简称连接词与独立公司全名，同时保留独立声明的完整名称。
- PDF 遮盖边距避开相邻字符；粗文字框含有额外正文时改由人工框选。点击“去定位”后可重新拖框，不再被旧候选或原区域拦截。

## 安装与复测

在 DSH 插件管理中添加 `dsh-document-redactor-1.4.3-dev.2.tgz` 的完整本地路径，按提示启用或重新加载。更新前保留原件及映射，不删除用户数据目录。命令行方式：

```sh
dsh plugin --profile desktop add "/完整路径/dsh-document-redactor-1.4.3-dev.2.tgz"
```

旧项目缓存不会自动获得新识别结果。请从原始文件重新识别；必要时重新上传为新项目。检查人名、公司名、正文边界、签章及跨页案号，处理全部提示，再核对导出文件。自动候选可能漏识别，人工补框和最终复核仍然必要。

## 验收范围

- 图像反馈批次：8 项定向、PDF 集成、Python 36／Node 42 回归和 macOS Chrome 单 PDF 闭环。
- 正文误遮批次：10 项定向、构造 PDF 应用集成、Python 46／Node 42 回归基线；之后只修改手工框选事件入口，补充 JavaScript 语法、事件函数定向检查及同一 Mac Chrome 恢复核验，未重复全量。
- 构造样本中 4,530 个蓝色正文像素未被修改；实际下载与同编码预览逐像素一致，原始文件保持不变，导出无文字层或链接。
- 粗框人工恢复场景在测试会话中主动注入候选，用于验证通用防护与操作入口，不作为自然 OCR 效果证据。集成末端颜色阈值检查受 JPEG 编码影响，改为同编码预览比较，未重跑整轮集成。
- 当前安装包只构建一次。发布复用既有回归和浏览器证据，未重打包或调用模型。本机日常 DSH 0.2.2-rc.1 已安装同一包，正式入口可启动并显示上传页。

Windows 新路径、此次 Word 路径及反馈录屏对应的原 PDF 尚未复验。本版以预发布方式提供复测，不将构造样本结果推广为所有文书均能自动正确处理。
