# 文书脱敏工作台 v1.4.0

本版改进首次安装与失败恢复、异常照片 PDF 导入、规则回退，以及逐行 OCR 核对。沿用预发布渠道，Windows 新增路径仍待现场复验。

## 本版变化

- 安装依赖时显示准备阶段，可选择系统默认、PyPI 官方或清华 TUNA 源；选择只影响本插件。失败、取消或达到20分钟期限后，可保留已有依赖与缓存重试，不清空文书和规则。
- requirements 显式声明 UTF-8；Windows 环境检查包含 OCR 后端、模型初始化和 WinRT 组件。
- PDFium 仍能正常渲染的结构异常 PDF，原件链接统计失败时显示未知并继续复核；导出仍像素重建并严格检查链接。真正不可读或未解密的文件仍报错。
- 规则助手支持放弃方案和应用历史回退。先查看差异，再确认恢复到所选应用前的完整规则；其后改动也会撤销，删除自定义规则仍须确认。应用或回退后须重新上传识别。
- 展开本页全部缓存 OCR 行，包括未命中、低分和无法定位的行；有坐标时可点击定位。人工核对标记独立保存，不解除候选处置或导出门禁。

同时修复连续 TXT／Word 导出时自定义规则正则未重新加载的问题。安装说明明确完整 TGZ 路径、Windows 删除外层引号、保留路径内空格及无需解压。

## 下载与安装

下载 [dsh-document-redactor-1.4.0.tgz](https://github.com/rainbowzhu22-eng/dsh-document-redactor/releases/download/v1.4.0/dsh-document-redactor-1.4.0.tgz)，在 DSH“插件 → 添加插件”填写本机 TGZ 的完整路径。Windows 与 macOS 使用同一包。具体步骤见 [安装说明](INSTALLATION-1.4.0.md)。

SHA-256：`05ab22909279123e72879f8aa3e47b148f945a10ba8ad49b453ff2254b7cfcd5`。同页提供 `SHA256SUMS.txt`，无需解压 TGZ。
