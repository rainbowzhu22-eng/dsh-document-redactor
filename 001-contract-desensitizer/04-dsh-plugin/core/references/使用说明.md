# 法律文书脱敏助手｜产品使用说明

> 2026-10-30 当前 PDF 规则：已检出的未处置项须先完成处理或明确保留，默认未选中不等于明确保留；风险知悉不能跳过。已有可用位置的待确认项可选择“自动处理”。修改或删除遮盖导致处置失效时，会重新阻断导出。其他识别失败、扫描停止及零处置提示沿用原规则。以下 R89 等历史记录不覆盖本条。

适用于 v1.3.0-dev 开发候选版 Mac / Windows 工具。安装方法见各平台安装说明；本说明介绍装好后的日常操作。操作以当前页面和本说明为准。

工具把文书中的敏感文字替换成占位符，例如`甲方示例科技有限公司`→`[主体#1]`。首次安装依赖需要联网，安装完成后文书处理不联网，也不调用云端模型。自动识别可能漏项，需要人工核对。

## 1. 打开工具

Mac双击桌面的 **“法律文书脱敏助手（WorkBuddy）.app”**；停止本机服务时双击 **“停止法律文书脱敏助手服务.app”**。Windows双击 **“法律文书脱敏助手（WorkBuddy）.bat”**。浏览器会打开“文书脱敏 / 还原”页面。macOS入口使用安装时记录的技能目录；虚拟环境缺失时会尝试回退到系统Python并由启动器恢复环境。

日常使用不需要输入命令。使用完毕可点击网页右上角 **“退出”**，停止本地服务；Mac也可双击桌面的停止应用。启动工具后如果出现黑色窗口，请保持开启；关闭后将无法正常使用。

## 2. 选择操作，上传原件

选择 **“脱敏模式”** 或 **“还原模式”**，再上传文书。脱敏模式支持DOCX、PDF、TXT、MD；还原模式支持具有对应映射文件的文字文书，PDF原件须从本机项目取回。

合同、诉讼材料及其他文书使用同一脱敏流程。识别到的通用敏感信息、诉讼案号、公文/机构编号和法院名称均作为候选显示；由您在对照页逐项选择是否脱敏，不按文书用途切换不同默认处理规则。

点击上传区域选择文件，或把文件拖进去。单个文件不超过 100 MB；一次处理一份。

上传脱敏文件前必须选择金额、日期处理方式：“脱敏交易要素”会默认脱敏金额和日期；“保留交易要素”会默认保留金额和日期，并在复核页及导出检查中列出。未选择时不能开始上传，服务端也不会按文件格式替您选择。策略上传后不能在复核途中更改，需改选时请重新上传。PDF导出会重建为像素稿，不生成映射文件且不能用工具还原；无论选择哪种策略，上传页都会显示此限制。

PDF各页均尝试本机OCR补充识别：Windows默认使用RapidOCR；仅在RapidOCR导入阶段触发`ImportError`时尝试Windows系统OCR。系统OCR要求安装包中的Windows.Foundation、Windows.Foundation.Collections、Windows.Graphics.Imaging、Windows.Media.Ocr、Windows.Storage及Windows.Storage.Streams运行绑定可用，并且Windows用户语言配置已安装相应OCR语言包。缺少运行绑定或语言包时会按本页识别失败处理。RapidOCR模型缺失、初始化或识别运行异常、超时均按本页识别失败处理，不自动切换到系统OCR。macOS使用随包提供的Apple Vision程序`pdf_vision_ocr`。文字层页面保留原文字层并合并OCR候选；补充OCR失败或未取得结果会提示人工检查。识别失败或位置不可靠时，仍可在原页手工框选遮盖；Apple芯片Mac已有指定样本OCR实测，仍有漏识别，所有页面均须人工核对；Intel未实机验证。旧版`.doc`请先另存为`.docx`。

**案件或项目名称可以留空。** 若希望以后上传的同案文书复用手工添加的规则，请在这里填写一个固定名称，详见第 5 节。

点击 **“进入左右对比 →”**。

### PDF 的核对与导出

PDF会进入独立项目页，展示原页和实际导出预览。页码旁的状态点表示该页处理情况：绿色为已完成，橙色表示该页有机器提示（识别失败、未识别到文字、OCR结果未完整纳入等），可点击页面下方的提示条展开详情。扫描过程较慢，请耐心等待。文字层与OCR结果按位置合并重复候选；带文字层PDF按表格单元格和独立栏位分开匹配，单元格内换行按同一字段处理。跨行候选按命中的字符行分别高亮和遮盖，避免用一个大矩形覆盖中间的无关正文；若各行空间不足以放置代号，导出会清除原字而不覆盖相邻正文。

**扫描完成后，工具会自动完成大部分处置**：能精确改字的候选自动替换为`[类别#编号]`；有真实位置框但不能精确改字的候选（OCR分较低、词级/行级定位、跨行分段）自动按框处理，代号放不下时整体遮盖；行级框可能连带同行少量正文，侧边栏会标注“机器按行级框自动处理”，可一键撤销。实体把握较低、编号候选和缺少坐标的命中不自动处理：前两类默认保留原文并在侧栏提示，缺少坐标的命中列入“需你确认”红色分组。

每个候选提供三个按钮：**自动**（机器按坐标替换或按框处理）、**遮盖**（按候选真实框整体遮黑）、**保留**（明确保留原文）。单击原页中的候选高亮可在“自动/保留”间切换。印章、签名、漏识别文字可在原页拖动框选遮盖；已有遮盖可移动、调整或删除，均可撤销。补充漏识别内容时，在“高级”折叠区的“补充敏感原文”填写代号名称、原文及别名（用分号分隔），点击“查找并加入”，再核对新候选是否勾选。

PDF中的批注及批注人名称可能作为页面内容保留。工具不能单独识别并替换批注人名称；请逐页核对批注内容和批注人信息。导出PDF会将每页转换为图片，不保留文本层，可能无法搜索或复制。PDF不生成JSON格式的映射文件，无法通过映射还原。

评分是规则启发式值，不是经标注样本校准的正确概率。旧版PDF项目如果只保存实体分与OCR分取低值的综合分，升级后会保留并标为旧版综合分，不会推算成实体分或OCR分；旧项目不重新OCR，已有的勾选、明确保留和手工遮盖全部保留。

实体分表示字段类型判断，OCR分表示文字识别，定位几何表示候选范围是否有可靠字符坐标，三者分开计算。R89起定位按逐字符标签局部判断，一处粗定位不再拖累同页其他精确候选；空格没有字形框不再计为坐标不完整。实体分低于0.50的候选默认未选，仅在侧栏提示“实体把握较低，建议核对”，不阻断导出。OCR分低于0.70的候选由机器自动按框处理；定位坐标缺失、越界或页码未知的命中列入“需你确认”，可到所在页拖框遮盖或明确保留，未处理时会按原文导出并在导出前提示。低于0.30展示下限的规则命中不会列入候选清单，按页提示并在导出提醒中列出；计数是未去重的规则命中数。RapidOCR会对低于0.70的OCR行进行有限次数的局部放大重识别，仍可能漏读；低于0.35的OCR行、文字为空、字符框数量不符、OCR分数无效及分数未提供分别计数并提示人工检查。短框会缩短代号，机构、姓名、邮箱、电话、账号可分别显示O、P、E、T、B加原编号；至少八点字号仍放不下时只遮盖，不覆盖相邻正文。策略默认保留的金额、日期会在复核页和导出提醒中列出。

**导出为直接操作**：导出按钮前持续显示通用提示：“自动识别无法穷尽文书中的全部敏感字段，识别结果也可能有偏差，外发前请人工核对导出的文件。”该提示不要求确认、不阻断导出。点击“导出脱敏 PDF”即按当前处置生成文件，不要求逐页标记核对。识别失败页未确认、存在尚未处置的敏感内容、扫描已停止（未完成页按原文导出）或本次未应用任何替换/遮盖时，导出前会出现一次“我已知悉，仍要导出”确认；确认后可继续。其余信息（自动识别边界、空页、补充OCR未取得、策略保留的金额日期、链接移除数量、批注提醒、像素稿说明）作为无需处理的一般提示。导出提示不显示坐标或几何诊断。PDF中的外部链接目标不作为候选；导出重建页面时会移除可点击链接，页面上印出的网址仍是可见内容，应检查候选或手工框选。页面识别失败时建议先重试本页识别；识别失败页在导出前会提示未识别内容按原文导出。输出名称统一为`脱敏文书-001.pdf`。

“需你确认”分组中，页码未知的命中会明确标示“页码未知”，请在实际出现页逐处定位。跨行候选可以用多个框分别完整覆盖各行。

切页、缩放及刷新后，待办摘要继续显示当前项目状态；修改候选、遮盖或补录字段后，旧导出阻断原因和旧确认卡失效，导出时重新检查。成功导出后显示“导出完成”。“撤销最近更改”撤销最近一次候选或遮盖操作，可能涉及其他页。补录字段、同步同案规则及重试单页时，未改变的其他出现位置保留原有勾选和明确保留决定；被重识别页须重新核对，重试前的撤销记录会清空。

手工框选会遮盖框内的全部像素，包括普通正文；倾斜扫描页请按当前图像的实际位置框选，不能照搬未旋转页面的坐标。水印、签名与正文重叠时，遮盖可能同时影响正文，请缩小范围并逐页检查；需要保留被叠压正文时，应先从可编辑原稿另制副本。窄窗口采用纵向排列，请向下滚动查看原页、预览和导出操作。

原始 PDF 留在本机项目中。关闭浏览器或重启服务后，从 **“历史记录” → “继续处理 / 取回原件”** 打开项目。**“取回原始 PDF”** 会校验上传原件的 SHA-256；原件缺失时可用 **“重新关联原件”** 选择同一文件。只有脱敏 PDF 或文字映射表，无法恢复扫描像素和黑条下的内容。删除本机项目也会删除其中的原件副本。

## 3. 核对 Word / TXT / Markdown 的左右两侧

### 英语为主的合同

中文姓名重复匹配不扫描更长汉字词内部；若命中两侧均为汉字，仅在紧邻明确主体/姓名角色、称谓或“介词+动作”结构时传播。

复核页检测到英语为主的文书时会显示范围提示。当前英文规则覆盖受控字段标签下的姓名、地址、国际电话、常见公司法定后缀与简称；标题式公司名称中的单个小写品牌词仅按受限结构识别。部分身份/税务编号和银行标识依赖字段标签；它不是通用英文实体识别。逐项核对姓名、地址、电话、身份与税务编号、银行信息及金额；图片文字、未覆盖的简称或编号可通过“添加漏识别的字段”补录。

英文姓名按明确字段标签或签署结构提取，支持`attn.`、受控联系人复合标签、标签后的中文斜线/括号说明、成对引号昵称、`By: /s/`和点缩写；拼音姓名支持`Pinyin Name`、`Name (Pinyin)`、`Chinese Name (Pinyin)`、`English Name (Pinyin)`及`Romanized Name`等明确字段，兼容英文名与拼音组合、纯拼音姓名及大小写变化。同一联系人字段明确标注`English Name`、`Chinese Name`和`Pinyin Name`时，三种写法共用同一个姓名编号；中英文公司名只有在同一字段的括号结构或明确中英名称标签中才建立跨语言别名关系，原有同语言全称/简称归并保持不变。没有姓名标签的普通英文词组不会仅因看似拼音而判为人名。高置信确认的完整姓名会按词边界查找重复出现处，明确前置尊称与完整姓名共用编号。不把同姓、相似缩写自动当作同一人。普通行文中的Name、By等词不单独构成姓名证据，单独编号标签词也不当作合同编号。

英语诉讼与仲裁文书另覆盖：英文/境外案号（美国联邦、英国 Claim No.、中性引用、香港法庭代码、有机构词锚定的中文仲裁案号）；法院专名、`IN THE ... COURT` 标题与 `Court:` 标签；仲裁机构全称及有仲裁语境的`HKIAC`、`SIAC`、`LCIA`、`ICSID`、`CIETAC`、`SCC`缩写归组织机构；仲裁员组成行不作为法院名称，仲裁当事人公司名不作为姓名；角色标签与 caption/`v.`/BETWEEN 限标题区识别姓名；Address for Service 等送达地址；Attorney ID/SRA/Bar；DOB数字日期。`the High Court held`、`Court Road`、`the Claimant submitted`为负例。仍非通用英文实体识别。

选择“保留交易要素”时，裁决金额、仲裁费和裁决日期等金额/日期默认保留；对外发送前请确认是否需要逐项脱敏。

密钥/凭据只按已知令牌格式、私钥/JWT结构，或明确的密码、密钥、会话字段键值结构识别；候选仅覆盖凭据值。正文中单独出现`authorization`、`session`、`cookie`等普通词不会触发密钥候选。自动识别仍可能漏项或误报，外发前须复核。

- **左侧**：原文。高亮表示该处将被替换。
- **右侧**：脱敏后的占位符预览。
- **类型面板**：识别到的类型默认已勾选，不需要逐类手动开启。

类型面板现在随页面滚动，不会覆盖“添加漏识别字段”；面板末尾也有“＋ 添加自选字段”快捷入口。

想保留某类信息，取消该类型的勾选；想保留某一处，点击左侧对应高亮。取消后，该处原文会在右侧保留；再次点击可恢复。

“严重度”按钮只筛选类型面板的显示范围，不会自动取消其他类型。“全选”用于选择全部类型；“恢复全部位置”用于重新启用被单独取消的位置。

含批注的DOCX会把已识别的批注正文和批注插入人作为独立候选显示。对照页默认选择“保留并脱敏批注”，也可选择“保留但不脱敏批注”或“移除全部批注”。移除后批注和锚点不能通过mapping恢复；保留并脱敏时，mapping可恢复被替换的批注文字和插入人字段。若结构无法安全识别，可选择“保留但不脱敏批注”：批注及关联部件原样保留，不进入mapping；导出前须确认风险，并人工检查批注中的敏感信息。工具不能判断批注意见本身是否属于内部信息。

### DOCX修订模式的扫描、脱敏和还原

姓名和机构识别按字段上下文限制：`BUSINESS OWNER DETAILS`、`COMPLETED BY`和`SIGNATURE`等明确字段可识别其姓名值；`DATE COMPLETED`等日期字段不会作为姓名字段继续向下探测。英文公司后缀按公司名称结构匹配；普通语句中的`Company as`和前置的`We,`不应进入公司名称候选。

页眉页脚中的可提取文字会参加扫描，但图片、脚注/尾注、字段指令、复杂绘图和部分未支持修订等内容可能无法自动处理。复核页使用一条通用提示，不逐类展开检查清单。导出前将未处理范围合并为一次知悉提示，最多列出五类实质风险；无法自动改写的已选文字会列出类型、原文和位置，知悉后可按原文导出，并在Word中搜索后手动处理。低置信候选、按选择保留的字段及移除外链等非阻断信息在导出结果中汇总。未处理内容不写入JSON格式的映射文件。DOCX包损坏、XML无效、写入错位或完整性校验失败仍会阻止生成文件。VML水印支持一个非空文字路径及被形状引用的静态空文字模板；额外文本或复杂结构可能保留原文并列入提示。

DOCX在对照页提供统一的批注与修订设置。经校验的正文、页眉和页脚标准新增/删除文字修订及修订人可作为候选参加扫描、复核、脱敏和JSON格式映射文件还原；受支持修订默认保留并脱敏。工具保留修订标记，不会自动接受、拒绝或移除修订。未能安全改写的已选修订文字会列入导出前提示；您知悉后可继续导出，未处理内容按原文保留。

工具分别检查接受修订和拒绝修订后的文字，所以拆在多个Word文字片段中的姓名、机构名称和日期会按组合后的完整内容识别。相同文字位置同时命中多个类型时，导出时会合并为一次写入，并列显示各类型占位符；连续的部分重叠范围按并集写入。mapping记录全部类型和原文，还原时恢复一次。无法组成连续范围、物理结构不一致或位置校验失败时仍会阻止处理。姓名识别中，“员工”“法人”等无冒号普通词不会单独作为强姓名标签；明确字段标签后的姓名仍可进入候选。

正文、表格、页眉和页脚中的普通文本框（包括VML/DrawingML结构），以及简单、未绑定的纯文本内容控件，已纳入敏感信息扫描、复核、脱敏和映射还原；外发清理会校验其结构。符合简单VML文字路径结构的纯文字水印也会扫描、脱敏并纳入JSON格式的映射文件。这里说的文本框包括通过Word“插入→文本框”添加的文字，也包括输入在矩形、箭头等绘图形状里的文字；它们不同于普通正文段落。Word为兼容不同版本保留的备用文本框副本（例如VML与DrawingML两种显示版本）无法确认是否都已同步脱敏；页面只显示通用风险说明。受支持的隐藏文字会纳入扫描和脱敏，同时保留隐藏格式。脚注/尾注正文、字段代码、复杂绘图水印、图片内容及部分未支持修订可能无法自动脱敏。能够安全保留的未扫描内容和未能自动改写的已选项按原文导出；导出前把风险合并为一次知悉确认，最多列出五类实质风险。未能自动改写的已选内容会列出类型、原文和位置，供导出后在Word中搜索处理。低置信未选项和按选择保留的信息仅在导出后汇总。工具不会验证未处理内容是否仍含敏感信息，也不会把未处理内容写入mapping。普通字段只扫描可见结果，不扫描指令本身。盘点不完整本身不代表DOCX损坏；可识别部分继续处理，无法确认范围的修订原样保留并在导出前简短提示。XML损坏、写入错位或完整性校验失败仍会阻止导出。只开启“修订”记录设置但没有修订内容的文件不按含修订文件拦截。

修订文字和修订人会在左右对比页作为候选复核。受支持修订默认保留并脱敏，新增、删除内容仍会向接收方显示；**工具只处理识别到的敏感信息，不能判断这些谈判信息是否适合披露**。**如需对外发送干净版本，请先在Word副本中处理修订后重新上传**。导出前的知悉确认只说明您已了解提示内容，不代表工具验证了未扫描或未处理内容。跨制表符、换行等控制符而无法安全定位的已选候选会按原文保留并列入提示；结构和完整性检查仍会阻止不安全文件生成。

JSON格式的映射文件可还原工具实际替换的普通文本框、简单VML文字水印、简单未绑定内容控件、修订文字、修订人、正文和批注候选。脱敏件未被改动时按输出文件哈希还原；仅重新保存、目标结构未变时可按唯一目标和结构校验兼容还原。修订被接受/拒绝、目标结构改变、占位符被改写或目标不唯一时会停止还原。未扫描且原样保留的兼容分支、脚注/尾注、复杂水印、图片文字和字段指令不会写入映射，也不会由映射文件还原。上传源文件不会被工具改写；请始终保留原始DOCX和对应JSON格式的映射文件。

诉讼案号、法院名称和公文/机构编号会与其他敏感信息一并作为候选显示。案号与公文/机构编号根据格式分类；当格式不足以区分时显示为“编号候选，类别待核对”，默认不勾选。分类仅描述格式匹配，不推断编号来源。法院名称为独立候选。当事人和证人姓名沿用姓名规则。姓名、机构、地址等仍可能漏识别；医疗信息、商业秘密通常需要手工补充。

## 4. 添加漏识别的内容

在对比页上方找到 **“添加漏识别的字段”**，填写：

| 输入项 | 含义 | 示例 |
|---|---|---|
| 字段名 | 替换后显示的类别名称 | 主体 |
| 原文 | 文书中需要替换的完整文字 | 甲方示例科技有限公司 |
| 别名 | 同一主体的简称或其他写法，多个用逗号分隔 | 示例科技 |
| 使用范围 | 只用于本文，或供本案后续上传沿用 | 只在当前文书使用 |

点击 **“添加并重新识别”**，再检查左右两侧。添加后页面会重新识别，请重新核对勾选状态。

这里添加的是**指定文字及其别名**，不是创建一个能自动识别所有同类信息的新规则。例如字段名填“医疗信息”后，仍需要填写具体原文，工具不会因此自动找出所有疾病名称。

同一原文出现多次时，会一起成为候选项；不想替换其中某处，可单独取消。底色、加粗等格式不决定是否匹配。如果文书中的写法不同，请把实际写法补充为别名。

## 5. 让后续同案文书沿用规则

例如一个案件有起诉状、答辩状和证据目录：

1. 上传起诉状时，案件名称填写 **“海星案”**。
2. 添加漏项时，选择 **“本案后续上传也使用”**。
3. 以后上传答辩状或证据目录，也填写完全相同的 **“海星案”**。
4. 已保存的自选原文和别名会参与新文书的识别，仍须核对结果。

该功能用于复用自选规则。它不会批量处理所有文件，也不会自动更新已经导出的文件；旧文件需要重新上传处理。

未填写案件名称时，自选字段只能用于当前文书。同案规则保存在这台电脑本地，换电脑不会自动同步。

## 6. 生成、保存与外发

核对全文后，点击 **“确认并执行脱敏”**。

Word复核页和PDF导出按钮前会显示相同的提示：“自动识别无法穷尽文书中的全部敏感字段，识别结果也可能有偏差，外发前请人工核对导出的文件。”其下以灰色小字说明可能未识别的敏感内容会按原文保留。导出前如出现知悉提示，您可以返回复核，也可以确认后继续导出；Word确认卡中的具体未扫描项也以灰色小字列出。未处理原文和位置会随导出结果列出；外发前请打开最终文件人工核对。

脱敏成功后生成脱敏文书和JSON格式的映射文件。脱敏文书自动保存；“下载JSON格式的映射文件”默认未勾选。您可勾选该项，在脱敏成功后下载映射文件，也可在成功结果区单独另存。支持的浏览器可通过**“选择保存文件夹…”**指定保存位置。未选择文件夹时，浏览器可能询问保存位置，也可能按浏览器中设置的位置自动保存。导出名沿用源文件名；请检查文件名，如其中含敏感信息，请自行重命名。映射文件下载未成功时，可在成功结果区点击**“另存JSON格式的映射文件”**。导出失败时没有本次映射文件的另存入口。

| 文件 | 用途 | 如何保管 |
|---|---|---|
| 脱敏文书 | 给接收者阅读和审阅 | 下载后打开，检查正文、表格、页眉页脚和排版 |
| `*.mapping.json` | 将占位符还原为敏感原文 | 含原始敏感文字，按原件保管，不随脱敏稿外发 |

若以后需要还原，请单独保存映射文件，并与脱敏稿分开保管。新生成的 DOCX 不内嵌映射文件。

DOCX导出会执行结构检查和安全清理，不因文书属于合同或诉讼而采用不同清理策略。批注默认保留并脱敏；遇到无法自动处理的批注或选择“保留但不脱敏批注”时，风险并入一次导出前知悉提示。受支持修订默认保留并脱敏。普通文本框、简单VML文字水印、简单未绑定纯文本内容控件和受支持的隐藏文字已纳入扫描；兼容文本框备用副本、脚注/尾注正文、字段代码、复杂水印、图片内容和部分未支持修订仍可能未扫描或未处理，按原文保留并并入简短知悉项。工具不验证未处理内容是否仍含敏感信息。确认后可继续导出；低置信候选、按选择保留的字段及移除外链等信息在导出结果汇总，不要求额外确认。DOCX损坏、XML无效、写入错位或完整性校验失败仍会阻止生成。DOCX默认移除全部外部关系并保留超链接显示文字；外链图片或对象可能不再显示。选择保留外部关系时，显示文字和符合规则的超链接目标参加扫描，保留关系的风险并入一次知悉提示；目标打开后的远端网页内容、其他类型关系目标及字段指令中的网址不扫描。请在外发前检查最终文件，并按导出结果列出的原文和位置处理未改内容。

无论文书将用于内部复核、交给外部顾问还是提交给外部AI，导出后都应打开最终文件，检查姓名、机构、地址、账号、案号、法院名称、批注、修订及其他应处理的内容。该工具不替代使用者对文书披露范围的判断。

## 7. 需要时还原文字

以下映射还原流程适用于支持该能力的文字文书；PDF 请在本机项目中使用 **“取回原始 PDF”**。

1. 返回首页，选择 **“还原模式”**。
2. 上传需要还原的脱敏文书。
3. 按页面提示选择与该文件对应的 `mapping.json`。
4. 点击 **“上传映射并还原”**，下载并检查还原结果。

请使用与该脱敏稿对应的映射文件。映射丢失后无法通过本工具恢复敏感原文。

还原用于回填被替换的文字。普通文本框、简单VML文字水印、简单未绑定内容控件、保留并脱敏的批注、受支持修订文字和修订人可随对应JSON格式映射文件还原；保留外部关系时，已替换的超链接目标敏感内容也可还原。按选择移除的批注、外部关系及文档属性等内容不会恢复；未扫描且原样保留的备用文本框、脚注/尾注、复杂水印、图片文字和字段代码不写入映射文件，也不会被映射文件还原。修订目标被接受/拒绝、改变结构或修改占位符后，映射校验失败时不会生成还原件。请始终保留原始文书。

## 8. 查看和清理本机历史

页面顶部的 **“历史记录”** 会列出本机已经保存的处理记录、产物和占用空间。PDF项目状态写入本机会话目录，服务重启后可从历史记录继续复核和重新导出；如果先前执行过“清理全部明文”，已删除原件及页面缓存的项目不能继续复核。DOCX、TXT、Markdown的旧复核页勾选状态保存在进程内存中，服务重启后不能恢复，须重新上传。

单条记录旁的“删除”会尝试删除该记录对应的会话目录，目录删除失败时页面会提示错误；不要把浏览器下载目录或原位置源文件视为工具可管理的留存内容。批量“清理全部明文”按当前规则尝试清理工具数据目录内的上传文书副本、PDF私有缓存、项目状态及符合命名规则的映射、日志和临时文件，已完成的脱敏稿保留。电脑原位置上的源文件、浏览器下载或用户另存文件、案件/项目自选规则及会话目录外的文件不在本次范围，不符合命名规则的映射也可能保留。

## 9. 常见问题

**没有看到某个类型，怎么办？**

类型面板只显示本次识别到的候选类型。没有显示不代表文书中没有这类信息，请查看全文，并按第 4 节补充漏项。

**网页提示本地服务已停止，或出现连接中断？**

请重新运行桌面启动器并等待服务就绪。启动工具后如果出现黑色窗口，请保持开启；关闭后将无法正常使用。上传页连接失败提示后可点击 **“检测本地服务状态”** 重新检查。上传失败时工具不会自动重传，先查看历史记录确认是否已生成项目。服务重启后未清理明文的PDF项目可从历史记录继续；已清理明文的PDF不能继续复核。DOCX、TXT、Markdown的未完成复核须重新上传。

**添加了原文，但没有出现高亮？**

核对填写文字是否与文书中一致，是否存在空格、换行或不同写法。可以从左侧原文复制实际文字，或把不同写法添加为别名。

**“本案后续上传也使用”无法选择？**

本次上传未填写案件名称。若需要同案沿用，请返回首页，填写案件名称并重新上传。

**浏览器打不开工具？**

先重新双击桌面应用。仍打不开时，把报错截图交给 WorkBuddy，并请它检查本地服务和 Python 环境。不要把完整敏感文书附在报错截图中。

**关闭网页后，原件会自动删除吗？**

不会。上传原件、处理结果和同案规则可能保存在本机会话目录中，关闭网页或退出服务不等于删除文件。共享电脑使用完毕后，请妥善管理本地材料。

### R84补充：减少导出误拦及PDF重复定位

以下为R84历史交互记录，不适用于当前界面。R89起已删除批量选框及逐页确认步骤，现行操作见前文“PDF复核与导出”。

（1）PDF已有位置合适的候选框时，可选择当前页待处理项并点击“采用所选现有框遮盖”。先查看黑色遮盖预览，再点击“确认所选项已被所选框遮盖”，一次确认当前页多处。此操作属于人工确认，不代表系统证明粗框包含全部文字。真正缺少坐标、越界或框错位的项才需要补定位；也可直接关联已经画好的遮盖框。

（2）多个框联合完整覆盖同一处文字时可计为已遮盖；有实际缝隙仍须补框。修改、删除关联框会使相关确认失效，须重新检查；只需重新核对受影响页。绿色表示已替换或已遮盖，灰色表示明确保留或按策略保留，橙色表示尚待处置。颜色不能替代导出清单。支持明确多选后批量保留原文，该操作与遮盖分开。

（3）普通文字控件的字体、段落及定位格式，以及完整的PAGE、NUMPAGES、SECTIONPAGES页码域（含安全格式开关、拆分指令、无缓存结果）不再因这些格式误拦。数据绑定、未知结构、未闭合域和外部指令仍按实际风险检查，不因控件名像页码就放行。上传复核页显示已分类的控件预检；不能据此保证所有复杂对象可导出。

（4）已选修订人属性按物理位置、旧值构造预期变化，各阶段校验同一预期；未选文字和结构仍受保护，不自动接受或拒绝修订。普通无修订DOCX预先计算正文及页眉页脚的逐段预期文字，明确未勾选的同值位置不会被当成页码控件残留。其他属性和复杂结构的全局同值误拦仍有兼容边界。

（5）可以明确确认“无替换导出”：替换0处，保留未选原文，仍执行结构检查和所选清理。没有可还原替换记录时不提供映射文件；不会改用旧映射，也不会因类型全未选而自动启用全部。浏览器导出清单绑定当前原件、选择、模式及规则快照，选择变化后须重新确认。旧客户端沿用既有确认检查；此快照不是用户认证机制。

（6）识别增加户籍地等地址标签及受控行政层级续行，修正机构名称内部连词造成的前缀截断；支持受控的“姓名律师”“律师姓名”及已确认姓名的律师语境传播。姓名替换保留“律师”称谓。识别仍可能漏项，地址换行不按任意正文无限续接。

## 10. 自定义识别规则（可选，交给 AI 修改）

首页提供“打开规则文件”按钮和“想修改字段识别规则？可将规则内容交给您选择的AI Agent协助修改（本工具不会连接AI Agent；点击展开操作说明）”折叠说明。识别规则保存在本机独立目录，安装和升级都不会覆盖你的修改：

| 系统 | 规则文件位置 |
|---|---|
| Windows | `%LOCALAPPDATA%\ContractDesensitizer\Rules\脱敏规则清单.md` |
| macOS | `~/Library/Application Support/ContractDesensitizer/Rules/脱敏规则清单.md` |
| Linux | `~/.local/share/contract-desensitizer/Rules/脱敏规则清单.md` |

修改规则的建议流程：

1. 点击“打开规则文件”，先确认软件已自动保留的备份（同目录 `Backups\`，按内容保存最近20份快照，另有 `last_valid.md` 为最近一次通过校验的版本）。
2. 把规则全部内容和你想修改的要求粘贴给你自己选择的 AI Agent（首页和规则文件内都提供可复制提示词）。只发送规则和虚构示例，不要发送真实合同、客户信息或原文映射；完整规则文件会离开本机，是否到达云端取决于你选择的 AI 服务。软件本身不连接 AI、不上传任何文件。
3. 把 AI 返回的完整内容保存回规则文件，使用 **UTF-8 编码**，不要混入解释文字，也不要用代码围栏（三个反引号）包裹内容。
4. 重新上传一份虚构测试文件核对识别与导出；出问题可在上传页点击“恢复上一份有效规则”。

规则文件每次上传前都会校验：只有 `## 规则表` 标题下的连续表格行会被解析；默认规则行必须齐全（停用请把“默认启用”改为“否”，不要删行）、序号和规则名不得重复、新增类型必须提供能编译的正则。删除自定义规则时页面会列出将被移除的类型，确认后才会继续。自定义正则由具备超时能力的 regex 组件限时执行，超时会中止本次识别并明确提示。自定义规则作用于 DOCX/TXT/Markdown 的上传识别；PDF 项目识别暂不使用自定义规则。

该目录及备份不受“清理全部明文”影响；如需彻底删除，卸载工具后手动删除上述 `Rules` 目录即可。
