# 贡献说明

本项目是 DSH 文书脱敏插件。请先在 Issue 中说明可复现问题、预期行为、系统及 DSH 版本；修改保持集中，并提供必要的定向验证。

只使用虚构样本；不要附真实文书、映射、密钥、完整宿主配置或未经处理的日志。Windows 未验收问题应保留原状态，不因源码检查通过改成实机通过。

`core/BASELINE.json` 固定 R99 引擎的文件摘要。变更引擎前应明确影响及来源，不随意改摘要掩盖代码变化。Agent 规则修改不得绕过复核、并发检查或 PDF 导出门禁。

提交的原创代码沿用本仓库适用许可；第三方内容保留原作者、来源与许可，不将其他项目的新许可追溯套用到本包。
